# 웨딩 사진 폴더

실제 사진을 이 폴더에 저장하세요. WebP 형식을 권장합니다.

현재 사용 중인 파일명:

- `cover-v1.webp`: 첫 화면 대표 사진
- `share-v1.webp`: 카카오톡 및 링크 공유 썸네일
- `gallery-01-v1.webp` ~ `gallery-06-v1.webp`: 갤러리 사진

권장 크기:

- 대표 사진: 긴 변 1600px 이내, 500KB 전후
- 갤러리: 긴 변 1400px 이내, 사진당 200~500KB

사진을 교체할 때는 브라우저와 카카오톡 캐시를 피하도록 `v2`, `v3`처럼 새 파일명을 사용하고 `app/wedding-config.ts`와 `index.html`의 경로를 함께 변경하세요.
